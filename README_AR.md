# ⚡ Flix Cloud — استضافة بوتات ومواقع (بوت تيليجرام + موقع إدارة)

يستضيف **بوتات Python و Node.js** و**مواقع ويب** (Python / Node / HTML) ويعطي كل موقع **رابطاً**، مع **لوحة ويب فخمة** و**بوت تيليجرام** كاملين — من نفس الجهاز، بدون Docker وبدون أي خدمة استضافة خارجية.
كل الملفات في **الجذر** (بدون مجلدات) ليسهل رفعها على GitHub وتشغيلها على Render وغيره.

## التشغيل السريع
**محلياً / VPS:** `cp .env.example .env` ← ضع `BOT_TOKEN` و`ADMIN_ID` ← `python run.py`
**Render:** ارفع الملفات لمستودع GitHub ← New → Blueprint (يقرأ `render.yaml`) ← أدخل `BOT_TOKEN` و`ADMIN_ID`.
**katabump وأمثالها:** ملف التشغيل `app.py` (أو `run.py`) + متغيرات البيئة.
> `run.py` مشرف يعيد تشغيل `app.py` تلقائياً عند أي انهيار (24/7). `python app.py` للتشغيل المباشر.

## ما الذي تحصل عليه
### 1) لوحة الويب (على نفس الرابط `/`)
* **الحسابات تُنشأ من المالك/المشرفين فقط** (لا تسجيل عام). كلمات المرور PBKDF2، جلسات HttpOnly + CSRF، وحماية من تخمين كلمة المرور.
* للمستخدم: رفع مشروع (ملف / ZIP بالسحب والإفلات)، تشغيل/إيقاف/إعادة، **سجل حي**، **محرر ملفات**، **طرفية** آمنة (`pip/npm/node/python`)، متغيرات `.env`، تثبيت المكتبات، تحليل المشروع، رابط الموقع.
* للمالك/المشرف: إدارة الحسابات (إنشاء/تعطيل/إعادة كلمة مرور/حد المشاريع/حذف)، كل المشاريع، **موارد النظام** (CPU/RAM/قرص)، **سجل العمليات**، وإعداد الرابط العام. المالك فقط ينشئ المشرفين.
* أول تشغيل: يُنشأ حساب المالك (`OWNER_USERNAME`/`OWNER_PASSWORD` — وإن تُركت فارغة تُولَّد وتصلك على تيليجرام). استرجاع: `/webpass`.

### 2) بوت تيليجرام (كل أوامره القديمة محفوظة)
رفع مشاريع، موافقات، نقاط، اشتراكات، لوحة أدمن، ... والمضاف: `/links` `/slug` `/public` `/rewrite` `/analyze` `/web` + للمالك `/webadd` `/webusers` `/webpass` `/seturl` `/setdomain` `/diag` `/sysstats` `/gateway`.

### 3) 🎨 استوديو الستايل (`/studio` — للمالك)
* **11 ستايل جاهز** (كلاسيك · محيط · غابة · غروب · ليلي · ذهبي · وردي · سايبر · نيون · ترمنال · بسيط) + ستايلاتك من `themes.json`.
* **معاينة قبل التطبيق** (على رسالة وعلى قائمتك الفعلية)، تراجع، إعادة ضبط، تصدير/استيراد JSON (تعديل يدوي).
* **تحرير أي زر**: النص، الأيقونة، اللون، الإخفاء، الترتيب (⬆️⬇️)، عدد الأعمدة — لكل شاشة.
* **تخصيص الإطار**: الاقتباس (عادي/قابل للطي/شريط/صندوق كود/بدون)، رموز النقاط، الفواصل، الأسهم، شريط التقدم، المؤشر المتحرك، ترويسة وتذييل.
* **تحرير نصوص البوت** كلها.
* **أزرار مخصصة** (رابط / نافذة منبثقة / السورس) تضيفها للقائمة الرئيسية.
* **زر «السورس»**: عند الضغط يظهر **فيديو مموّه (Spoiler)** مع **نص داخل اقتباس** وأزرار روابط. تعيّن الفيديو والنص من الاستوديو، والتمويه يُشغَّل/يُوقَف.
* **أدوات**: `/countdown 60` عد تنازلي بشريط تقدم · `/anim` شاشات متحركة (7 مؤشرات) · `/term` شاشة ترمنال لحالة السيرفر.
* **إضافات**: أي ملف `plugin_*.py` بجوار البوت يُحمَّل تلقائياً (انظر `plugin_example.py`) وفيه `register(core, ui)` تضيف به أوامر وأدوات جديدة.

### 4) استضافة المواقع
| النوع | كيف يُكتشف | الرابط |
|---|---|---|
| موقع HTML | `index.html` بدون كود خادم | `/s/اسم/` |
| Flask / FastAPI / Express / ... | يفتح منفذ ويب (يُكتشف تلقائياً حتى لو ثابت في الكود) | `/s/اسم/` + WebSocket + رفع ملفات |
* مع المسار `/s/اسم/` تُصلَح الروابط المطلقة وإعادة التوجيه والكوكيز. للتوافق الكامل مع التطبيقات المعقدة استخدم النطاق الفرعي: `/setdomain example.com` (يلزم Wildcard DNS).
* إن لم يوجد Node على السيرفر يُنزَّل مرة واحدة من nodejs.org (يحتاج إنترنت لهذه الخطوة) ويُحفظ في `runtime/`.

## الاختبار
`python run.py --selftest` يشغّل اختبارات حقيقية (بوتات Python/Node، مواقع HTML، Proxy، WebSocket، حسابات وصلاحيات اللوحة، الاستوديو). `python run.py --check` فحص جاهزية السيرفر. `/diag` من البوت.

## حدود صريحة (اقرأها)
* **Render المجاني**: القرص مؤقت (تضيع قاعدة البيانات والمشاريع عند كل نشر/إعادة تشغيل) وينام الموقع بعد خمول. للاستمرارية استخدم قرصاً مدفوعاً (انظر `render.yaml`) أو VPS.
* تثبيت مكتبة **جديدة** يحتاج الوصول لـ PyPI / npm (أو وجودها في كاش `runtime/cache/`).
* العزل بين المشاريع على مستوى العمليات والمجلدات وليس حاويات: لا تستضف كوداً من أشخاص لا تثق بهم. الحسابات تُنشأ من الإدارة فقط لهذا السبب.
* ألوان الأزرار (أزرق/أخضر/أحمر) وتمويه الفيديو يعتمدان على إصدار Bot API وتطبيق تيليجرام لدى المستخدم؛ حدّث `pyTelegramBotAPI`.
* الاختبارات استخدمت بديلاً محلياً لتيليجرام (لا اتصال بالشبكة): منطق الاستوديو واللوحة والبوابة مُختبَر، أما الشكل النهائي داخل تطبيق تيليجرام الحقيقي فعليك معاينته من `/studio`.
